# 🍔 Delivery App - FlutterFlow API

## 📱 Sobre o Projeto
Este repositório contém um aplicativo de Delivery desenvolvido utilizando a plataforma **FlutterFlow**. O foco principal deste projeto é demonstrar a integração de uma interface mobile com APIs externas (REST) para o gerenciamento dinâmico de dados. O app foi estruturado para oferecer uma experiência fluida aos usuários, cobrindo desde a navegação pelo cardápio do restaurante até a finalização e acompanhamento do pedido.

## ✨ Funcionalidades
- **Autenticação de Usuários:** Fluxo de login e cadastro de clientes consumindo dados da API.
- **Catálogo de Produtos:** Listagem dinâmica das categorias e dos pratos/itens disponíveis.
- **Carrinho de Compras:** Gerenciamento local e remoto de adição, remoção e quantidade de itens.
- **Checkout:** Tela de finalização de pedidos, envio de dados de entrega e integração de pagamento.
- **Meus Pedidos:** Histórico e acompanhamento do status do pedido em tempo real.
- **Integração REST API:** Todo o núcleo de dados do aplicativo é alimentado por endpoints externos configurados de forma nativa no FlutterFlow.

## 🛠️ Tecnologias Utilizadas
- **FlutterFlow:** Ferramenta *low-code* de construção visual de interfaces.
- **Flutter & Dart:** Framework de UI do Google e sua linguagem de programação base.
- **REST APIs:** Arquitetura de comunicação com o backend/banco de dados do sistema.
